🧰 我的工作台 — 使用说明
==========================

📱 如何使用
-----------
1. 在手机或电脑浏览器中打开 index.html 文件即可使用
2. 推荐用 Chrome / Edge / Safari 浏览器打开
3. 手机端：浏览器菜单中选择「添加到主屏幕」，即可像 App 一样使用
4. 电脑端：可直接在浏览器中使用，也支持桌面通知提醒

📋 功能模块一览
---------------
🏠 首页      — 今日概览：待办数、收入、健康打卡、快捷操作入口
✅ 计划      — 每日计划打卡清单 + 学习备考 + 读书记录 + 运动记录
📝 记录      — 灵感存档 + 每日总结(日记) + 赚钱记账
❤️ 健康      — 健康习惯提醒 + 喝水/拉伸/护眼快速打卡
📦 管理      — 订单管理(增删改查) + 工具网址导航 + 数据导入导出

🔔 健康提醒
-----------
- 首次使用时会询问是否允许桌面通知，建议选择「允许」
- 开启提醒后，到时间会在电脑右下角弹出通知弹窗
- 支持自定义提醒间隔时间
- 手机端也会在页面内弹出提示

💾 数据备份
-----------
- 所有数据保存在浏览器本地，不会上传到任何服务器
- 建议定期导出备份：「管理」→「数据管理」→「导出数据」
- 换设备或清除浏览器数据前一定要先导出！
- 导出文件为 JSON 格式，可在新设备上导入恢复

🎨 界面风格
-----------
蓝白莫兰迪配色 + 玻璃拟态半透明效果
所有卡片采用统一的毛玻璃质感设计

❓ 常见问题
-----------
Q: 数据会丢失吗？
A: 数据存储在浏览器 localStorage 中。清除浏览器缓存/数据会导致丢失。
   请定期导出备份！

Q: 怎么在手机上像 App 一样使用？
A: 用手机浏览器打开 → 点击浏览器菜单 →「添加到主屏幕」
   （Safari 是分享按钮 → 添加到主屏幕）

Q: 桌面通知没反应？
A: 检查浏览器是否允许了通知权限。Chrome: 地址栏左侧锁图标 → 通知 → 允许

Q: 换个浏览器数据还在吗？
A: 不在。每个浏览器的数据是独立的。用导出/导入功能迁移数据。
