# 导航架构 · Navigation Architecture

> 本文档定义应用的页面结构、导航方式和路由映射。

## 1. 导航层级

```
工作台
├── 🏠 首页 (home)
│   └── 仪表盘：统计卡片 + 快捷操作 + 最近订单 + 最近总结
│
├── ✅ 计划 (plan)
│   ├── 📅 每日计划 (daily-plan) — 打卡清单 + 运动方案
│   ├── 📚 学习备考 (study) — 学习记录日志
│   ├── 📖 读书记录 (reading) — 阅读记录日志
│   └── 🏃 运动记录 (exercise) — 运动记录日志
│
├── 📝 记录 (record)
│   ├── 💡 灵感存档 (inspiration) — 热门选题 + 灵感卡片
│   ├── 📝 每日总结 (summary) — 日记列表
│   └── 💰 赚钱记录 (income) — 收入表格
│
├── ❤️ 健康 (health)
│   └── 快速打卡 + 习惯设置 + 提醒开关
│
└── 📦 管理 (my)
    ├── 📋 订单管理 (orders) — 订单 CRUD + 状态筛选
    └── 🔧 工具导航 (tools) — 网址卡片 + 数据管理
```

## 2. 变量说明

| 变量 | 作用 | 可能的值 |
|------|------|---------|
| `currentTab` | 主标签页 | `"home"` `"plan"` `"record"` `"health"` `"my"` |
| `currentSubTab` | 子标签页 | `"daily-plan"` `"study"` `"reading"` `"exercise"` `"inspiration"` `"summary"` `"income"` `"orders"` `"tools"` |

## 3. 手机端导航（< 768px）

### 3.1 底部标签栏

```
┌──────────┬──────────┬──────────┬──────────┬──────────┐
│   🏠     │    ✅    │    📝    │    ❤️     │    📦     │
│  首页    │   计划    │   记录    │   健康    │   管理    │
└──────────┴──────────┴──────────┴──────────┴──────────┘
```

- 高度：64px
- 5 个主标签，每个有 Emoji 图标 + 中文标签
- 当前选中标签显示为莫兰迪蓝色
- `position: fixed` 固定在底部
- 需要适配安全区域：`padding-bottom: env(safe-area-inset-bottom, 0)`

### 3.2 子标签切换

- 主标签内的子页面通过**横向滚动的 pill 标签**切换
- 样式：圆角药丸形按钮，选中态蓝底白字
- 可左右滑动（`overflow-x: auto`，隐藏滚动条）

## 4. 桌面端导航（≥ 768px）

### 4.1 左侧边栏

```
┌──────────────┐
│ 📊 我的工作台 │  ← Logo
│              │
│ 🏠 首页      │
│ ✅ 计划      │
│ 📝 记录      │
│ ❤️ 健康      │
│ ──────────── │  ← 分隔线
│ 📦 订单&工具 │
└──────────────┘
```

- 固定宽度：220px
- 所有导航项展开，无需子标签聚合
- 子页面依然使用横向滚动 pill 标签切换
- 当前页高亮：蓝底 + 加粗

### 4.2 内容区域

- 左侧留出 220px 边距
- padding: 24px 32px
- 无底部导航栏

## 5. 页面切换机制

```javascript
// 主标签切换
switchTab(tab)  →  this.currentTab = tab
// 模板中: v-show="currentTab === 'plan'"

// 子标签切换
switchSubTab(sub) → this.currentSubTab = sub
// 模板中: v-show="currentSubTab === 'daily-plan'"
```

- 使用 `v-show`（非 `v-if`），保持 DOM 状态
- 页面切换有 0.3s 淡入动画

## 6. 弹窗/模态框路由

以下操作通过模态框实现，不属于页面路由：
- 新增/编辑订单
- 新增/编辑工具网址
- 新增/编辑习惯
- 新增/编辑每日任务
- 新增/编辑灵感
- 新增/编辑总结
- 新增/编辑收入记录
- 新增/编辑学习/读书/运动记录
- 确认删除弹窗
- 图片预览

## 7. 跨页面快捷跳转

首页的快捷操作按钮可以跨标签跳转：

| 快捷操作 | 目标标签 | 目标子标签 |
|---------|---------|-----------|
| 新增订单 | `my` | `orders` |
| 写总结 | `record` | `summary` |
| 记一笔 | `record` | `income` |
| 今日计划 | `plan` | `daily-plan` |
| 灵感存档 | `record` | `inspiration` |
| 喝水+1 | 不跳转 | 直接打卡 |

实现方式：
```javascript
this.switchTab('record');
this.switchSubTab('summary');
```

## 8. 状态保持

- 切换主标签时保留子标签状态（不清空 `currentSubTab`）
- 切换子标签时保持表单输入（`v-show` 不销毁 DOM）
- 模态框关闭时清空临时数据
- 页面刷新后回到默认首页（hash 路由可解决，但当前未使用）
