# 设计规范 · UI Design System

> **重要**: 本文档是项目 UI 的唯一权威标准。任何界面修改必须严格遵循此规范。

## 1. 设计理念

- **莫兰迪质感**：色彩低饱和度、灰调柔和，不刺眼，适合长时间使用
- **玻璃拟态**：半透明 + 模糊背景，营造层次感和空间深度
- **手机优先**：以 375px 宽度为基准设计，向上兼容平板和桌面

## 2. 色彩系统

### 2.1 CSS 变量完整表

```css
:root {
  /* ── 底色 ── */
  --bg:              #F2F0ED;     /* 暖灰白底，全局背景 */
  --card-bg:         rgba(255,255,255, 0.50);  /* 玻璃卡片半透明底 */
  --card-bg-hover:   rgba(255,255,255, 0.70);  /* 玻璃卡片 hover 态 */

  /* ── 主色（莫兰迪蓝）── */
  --primary:         #7B9EC7;     /* 主按钮、选中态、强调文字 */
  --primary-dark:    #5F7EA7;     /* 按钮按下 / hover 深色 */
  --primary-light:   #C5D5E8;     /* 大面积浅蓝底、次要元素 */
  --primary-bg:      rgba(123,158,199, 0.10);  /* 蓝色背景标记 */

  /* ── 文字 ── */
  --text:            #4A5568;     /* 正文 */
  --text-dark:       #2D3748;     /* 标题、重要文字 */
  --text-light:      #8B9CB5;     /* 辅助说明文字 */
  --text-lighter:    #B0BEC5;     /* 占位符、禁用态 */

  /* ── 语义色（莫兰迪调）── */
  --accent-green:    #8FAF8F;     /* 完成、收入、成功 */
  --accent-green-bg: rgba(143,175,143, 0.12);
  --accent-pink:     #C7A9A9;     /* 灵感、心情、温柔 */
  --accent-pink-bg:  rgba(199,169,169, 0.12);
  --accent-gold:     #C9B89A;     /* 提醒、待处理 */
  --accent-gold-bg:  rgba(201,184,154, 0.12);
  --accent-orange:   #D4A574;     /* 活力、运动 */
  --accent-orange-bg:rgba(212,165,116, 0.12);
  --danger:          #C7A0A0;     /* 删除、警告 */
  --danger-bg:       rgba(199,160,160, 0.12);

  /* ── 边框与阴影 ── */
  --border:          rgba(200,195,188, 0.35);
  --shadow:          0 4px 24px rgba(120,140,170, 0.06);
  --shadow-lg:       0 8px 40px rgba(120,140,170, 0.10);

  /* ── 圆角 ── */
  --radius-sm:       10px;   /* 小元素：标签、按钮 */
  --radius:          16px;   /* 默认卡片 */
  --radius-lg:       20px;   /* 大卡片、弹窗 */
  --radius-xl:       24px;   /* 模态框 */

  /* ── 动效 ── */
  --transition:      0.25s cubic-bezier(0.4, 0, 0.2, 1);
}
```

### 2.2 色彩使用规则

| 场景 | 使用变量 | 说明 |
|------|---------|------|
| 页面背景 | `var(--bg)` | 全局唯一底色 |
| 卡片、列表项、面板 | `.glass` 类 | 不要自己写 background |
| 主按钮、选中导航 | `var(--primary)` | 蓝底白字 |
| 次按钮、边框按钮 | `var(--primary)` 文字色 + 边框 | 透明底蓝边 |
| 完成/收入数字 | `var(--accent-green)` | 绿色正向 |
| 删除按钮 | `var(--danger)` | 粉红警告 |
| 待处理标签 | `var(--accent-gold)` | 金色提醒 |
| 灵感/心情 | `var(--accent-pink)` | 粉色柔和 |

## 3. 玻璃拟态规范

### 3.1 `.glass` 标准卡片

```css
.glass {
  background: rgba(255, 255, 255, 0.50);
  backdrop-filter: blur(12px);
  -webkit-backdrop-filter: blur(12px);   /* iOS Safari 必须 */
  border: 1px solid rgba(200, 195, 188, 0.35);
  border-radius: 16px;
  box-shadow: 0 4px 24px rgba(120, 140, 170, 0.06);
}
```

### 3.2 玻璃变体

| 类名 | 用途 | background | blur |
|------|------|-----------|------|
| `.glass` | 通用卡片、列表项 | `rgba(255,255,255,0.50)` | `12px` |
| 模态框 | 弹窗容器 | `rgba(255,255,255,0.85)` | `24px` |
| 确认框 | 小弹窗 | `rgba(255,255,255,0.90)` | `20px` |
| 底部导航 | 移动端底部栏 | `rgba(255,255,255,0.55)` | `20px` |
| 侧边栏 | 桌面端侧边栏 | `rgba(255,255,255,0.45)` | `16px` |

### 3.3 背景纹理

页面 body 上叠加了三层径向渐变，模拟莫兰迪画布的柔和质感：

```css
body {
  background-image:
    radial-gradient(ellipse at 20% 20%, rgba(123,158,199,0.08) 0%, transparent 60%),
    radial-gradient(ellipse at 80% 70%, rgba(199,169,169,0.06) 0%, transparent 60%),
    radial-gradient(ellipse at 50% 50%, rgba(201,184,154,0.04) 0%, transparent 70%);
}
```


## 6. 组件规范

### 6.1 按钮

| 类型 | 类名 | 样式 |
|------|------|------|
| 主按钮 | `.btn.btn-primary` | 蓝底白字，圆角 24px |
| 边框按钮 | `.btn.btn-outline` | 透明底蓝边蓝字 |
| 危险按钮 | `.btn.btn-danger` | 粉底（hover 变实心） |
| 小按钮 | `.btn.btn-sm` | padding 减半，字号 12px |
| 微小按钮 | `.btn.btn-xs` | padding 更小，字号 11px |
| 图标按钮 | `.btn-icon` | 36×36 圆形，玻璃底 |
| 浮动按钮 | `.btn-fab` | 48×48 圆形，蓝底白字，固定定位 |

### 6.2 输入框

```css
background: rgba(255, 255, 255, 0.70);
border: 1.5px solid var(--border);
border-radius: var(--radius-sm);
padding: 10px 14px;
font-size: 14px;
```

- Focus 态：边框变蓝 + 外发光 `0 0 0 3px var(--primary-bg)`
- Placeholder 颜色：`var(--text-lighter)`

### 6.3 模态框

- 遮罩层：`rgba(0,0,0,0.25)` + `backdrop-filter: blur(2px)`
- 内容区：玻璃强透 `rgba(255,255,255,0.85)` + `blur(24px)`
- 手机端：底部弹出，圆角仅顶部
- 桌面端：居中弹出，四周圆角
- 最大宽度：500px

### 6.4 Toast 通知

- 顶部居中，白色文字
- 成功：`#8FAF8F`（莫兰迪绿）
- 错误：`#C7A0A0`（莫兰迪粉）
- 信息：`var(--primary)`（莫兰迪蓝）
- 动画：淡入 + 上移 10px
- 自动消失：2.5 秒

### 6.5 确认弹窗

- 居中显示
- 最大宽度 300px
- 图标 + 文字 + 取消/确认按钮
- 危险操作用红色确认按钮

## 7. 响应式断点

| 断点 | 宽度 | 布局变化 |
|------|------|---------|
| 手机 | < 768px | 底部 5 Tab 导航，内容全宽，padding: 16px |
| 桌面 | ≥ 768px | 左侧 220px 侧边栏 + 右侧内容区，padding: 24px 32px |

### 手机端特殊规则
- 底部导航高度：64px
- 内容区下边距需额外 +64px（防止被导航遮挡）
- 安全区域：`padding-bottom: env(safe-area-inset-bottom, 0)`
- 禁用双指缩放：`user-scalable=no`
- 禁用文字选中：`user-select: none`

### 桌面端特殊规则
- 侧边栏固定宽度 220px，不可缩放
- 所有导航项在侧边栏中可见（不需要"更多"抽屉）
- 子 Tab 切换依然保留

## 9. 动画规范

| 场景 | 动画 | 时长 |
|------|------|------|
| 页面切换 | 淡入 + 上移 6px | 0.3s ease |
| 模态框打开 | 淡入遮罩 + 上滑弹窗 | 0.2s / 0.3s ease |
| Toast 出现 | 淡入 + 下移 10px | 0.3s ease |
| 按钮点击 | 缩放至 96% | 0.1s |
| 卡片 hover | 上移 1px + 阴影加深 | 0.25s |
| 卡片 click | 缩放至 98.5% | 0.1s |
