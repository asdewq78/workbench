# 数据模型 · Data Models

> 本文档定义所有 localStorage 数据表结构。
> **向后兼容规则**: 可以新增字段（设置默认值），但禁止删除或重命名已有字段。

## 概述

- 存储方式：`localStorage`，key 前缀 `db_`
- 序列化格式：JSON
- ID 生成规则：`"id_" + 时间戳 + "_" + 随机6位字母数字`
- 每条记录自动维护 `createdAt`（Unix 毫秒时间戳）

---

## 1. 订单 `db_orders`

```javascript
{
  id:          "id_1712345678_abc123",  // 唯一ID
  title:       "Logo设计",              // 订单标题
  customer:    "张三",                  // 客户名称
  amount:      299,                     // 金额（数字）
  status:      "pending",              // 状态: "pending" | "done"
  date:        "2026-07-30",           // 订单日期 YYYY-MM-DD
  notes:       "需要透明底",            // 备注
  createdAt:   1712345678000           // 创建时间戳
}
```

**筛选**: 按 status 筛选（all / pending / done）
**排序**: 按 createdAt 倒序
**金额显示**: `¥299`（整数不显示小数）

## 4. 健康打卡记录 `db_habitLogs`

```javascript
{
  id:      "id_1712345678_ghi012",
  habitId: "id_1712345678_def456",  // 关联 db_habits.id
  date:    "2026-07-30",
  time:    "14:30",                 // 打卡时间 HH:MM
  done:    true
}
```

**统计方式**: 按 date + habitId 分组计数
**快速打卡**: 喝水/拉伸/护眼按钮直接创建记录

## 5. 每日计划任务 `db_dailyTasks`

```javascript
{
  id:        "id_1712345678_jkl345",
  task:      "吃健康早餐",
  time:      "07:30",              // 时间 HH:MM（用于排序）
  completed: false,
  date:      "2026-07-30",         // 所属日期
  isPreset:  true                  // 是否预设任务
}
```

**预设任务**（每日自动创建）:
| 时间 | 任务 |
|------|------|
| 07:30 | 吃健康早餐 |
| 08:00 | 练习八段锦 |
| 09:00 | 阅读课外书 |
| 10:00 | 备考 |
| 14:00 | 练字 |
| 17:00 | 运动 |
| 21:00 | 护肤 |

**排序规则**: 按 time 字段升序排列
**每日初始化**: 每天首次打开时自动从预设创建当天任务
**跨日处理**: 未完成的任务不延续到第二天

## 数据版本兼容策略

1. **新增字段**：在 load 时检查字段是否存在，不存在则设置默认值
2. **删除字段**：禁止。旧数据会保留该字段，只是不再读取
3. **重命名字段**：禁止。需要写迁移脚本
4. **修改字段类型**：禁止。会导致旧数据解析失败

**导出格式**:
```json
{
  "orders": [...], "tools": [...], "habits": [...],
  "habitLogs": [...], "dailyTasks": [...], "inspirations": [...],
  "summaries": [...], "incomes": [...], "studyLogs": [...],
  "readingLogs": [...], "exerciseLogs": [...],
  "userName": "", "exportDate": "2026-07-30", "version": "1.0"
}
```
