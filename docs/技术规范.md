# 技术规范 · Technical Specification

> 本文档定义项目的技术选型、架构设计和代码组织方式。

## 1. 技术栈总览

| 层面 | 选择 | 版本/说明 |
|------|------|-----------|
| 前端框架 | Vue.js 3 (CDN) | 3.4.0，通过 jsdelivr CDN 加载 |
| CSS | 纯 CSS (Custom Properties) | 无预处理器，无框架 |
| 数据存储 | localStorage | 浏览器原生，key 前缀 `db_` |
| PWA | manifest.json + Service Worker | 离线缓存 + 可安装 |
| 通知 | Notification API | 浏览器桌面通知 |
| 部署 | 纯静态 | 任何静态文件服务器均可，或直接双击打开 |
| 构建工具 | 无 | 零构建、零依赖（除 Vue CDN） |

## 2. 为什么这样选

### Vue.js 3 CDN（非纯 JS）
- 11 个模块涉及大量列表渲染和表单操作
- Vue 的 `v-for`、`v-model`、`computed` 减少 80% 的 DOM 操作代码
- `Vue.createApp()` + Options API 无需编译，浏览器直接运行
- 生产版本（`.prod.js`）仅 ~120KB gzip

### 纯 CSS（非 Tailwind / UI 框架）
- 莫兰迪配色 + 玻璃拟态需要精细的 `backdrop-filter` 和透明度控制
- 任何 UI 框架都会带来样式覆盖成本
- CSS 变量体系让全局样式修改只需改一处

### localStorage（非 IndexedDB）
- 数据结构简单（每个模型一个数组），不需要复杂查询
- 5MB 限制对纯文本数据充足（图片 base64 需注意）
- API 最简单，JSON 序列化直接读写

### 单 HTML 文件（非多文件 + 构建）
- 目标用户不懂代码
- 双击即用，无需安装 Node.js、npm、任何工具
- 迁移到其他设备只需复制一个文件夹

### 4.2 数据流

```
用户操作 → Vue methods() → 修改 data 数组 → persist() → localStorage
                ↓
          computed 自动更新 → 视图自动更新（Vue 响应式）
```

### 4.3 页面切换

```
用户点击导航 → switchTab(tab) → currentTab 变化 → v-show 切换页面
用户点击子Tab → switchSubTab(sub) → currentSubTab 变化 → v-show 切换子页
```

## 6. PWA 架构

### 6.1 manifest.json
- `display: standalone` — 独立窗口运行（无浏览器地址栏）
- `theme_color: #7B9EC7` — 状态栏莫兰迪蓝
- `background_color: #F2F0ED` — 启动背景暖灰白
- `orientation: portrait-primary` — 竖屏优先

### 6.2 Service Worker 缓存策略

| 资源类型 | 策略 | 说明 |
|------|------|------|
| 本地文件（index.html等） | Network-first | 优先网络，离线用缓存 |
| CDN 资源（Vue.js） | Cache-first | 优先缓存，减少网络请求 |
| 旧缓存 | 新版 SW 激活时清除 | `dashboard-v1` → `dashboard-v2` |

### 6.3 PWA 限制

- 需要 HTTPS 或 localhost 才能注册 Service Worker
- `file://` 协议不支持 PWA 功能
- 推荐使用 `启动.bat` 启动本地服务器

## 7. 通知机制

```
setInterval 轮询（每30秒检查各习惯）
  ↓
检查是否到达提醒时间
  ↓
  ├─ 桌面通知：new Notification(title, options)
  │    └─ requireInteraction: true（需用户手动关闭）
  └─ 降级方案：showToast() 页面内提示
```

- 通知仅在浏览器标签页打开时生效
- 关闭标签页后定时器停止（纯前端限制）
- 同一习惯每分钟只提醒一次（防止重复弹窗）

## 9. 性能考量

- Vue 生产版本已做 tree-shaking
- `v-show` 而非 `v-if` 用于页面切换（避免重复渲染）
- 列表无虚拟滚动（当前数据量级不需要）
- 图片 base64 建议单张不超过 500KB
- localStorage 总占用建议不超过 4MB
