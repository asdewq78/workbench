# 需求文档 · Product Requirements

> 本文档是所有功能开发的唯一需求来源。新增功能前必须先更新本文档。

## 1. 项目概述

### 1.1 产品定位
「我的工作台」是一款手机优先的个人工作空间应用，集订单管理、每日计划、健康提醒、灵感记录、收入追踪等功能于一体。

### 1.2 目标用户
- 自由职业者 / 内容创作者 / 博主
- 需要统一管理日常工作的个人用户
- 不需要团队协作，纯个人使用

### 1.3 平台
- 手机端（主）：PWA 可安装到主屏幕，iOS Safari + Android Chrome
- 桌面端（辅）：Chrome / Edge 浏览器，支持桌面通知

### 1.4 核心原则
- 数据完全本地化，不上传任何服务器
- 离线可用
- 零注册、零登录、零费用

---

## 2. 全局 UI 规范

- 蓝白主配色 + 莫兰迪低饱和度质感
- 全部面板使用低透明度玻璃拟态（backdrop-filter blur）
- 清淡柔和，适合长时间使用
- 手机端底部 5 Tab 导航，桌面端左侧边栏

详见 [设计规范.md](设计规范.md)。

## 3. 功能模块

### 3.1 首页仪表盘
- 根据时间显示问候语（早上好/上午好/下午好/晚上好）
- 显示当日日期和星期
- 统计卡片：今日待办数、今日收入、健康打卡进度、学习时长
- 快捷操作：新增订单、写总结、记一笔、今日计划、灵感存档、喝水+1
- 最近 3 条订单
- 最近 3 篇总结

### 3.2 订单管理
| 功能 | 描述 |
|------|------|
| 新增 | 弹窗表单：标题、客户、金额、状态、日期、备注 |
| 编辑 | 点击订单卡片进入编辑弹窗，所有字段可修改 |
| 删除 | 点击删除按钮 → 确认弹窗 → 删除 |
| 状态筛选 | 全部 / 待处理 / 已完成 三个筛选项 |
| 列表排序 | 按创建时间倒序 |
| 金额显示 | 整数去小数 |

**数据字段**: title, customer, amount, status(pending/done), date, notes, createdAt

### 3.3 工具网址导航
| 功能 | 描述 |
|------|------|
| 预设网址 | 小红书、Pinterest、Instagram、ChatGPT（首次自动创建） |
| 新增网址 | 弹窗表单：名称、URL、图标Emoji、分类 |
| 编辑删除 | 每张卡片有编辑/删除按钮 |
| 跳转 | 点击卡片在新标签页打开网址 |
| 分类 | 社交媒体 / AI工具 / 英语学习 / 其他 |

**数据字段**: title, url, icon, category, createdAt

### 3.4 健康提醒
| 功能 | 描述 |
|------|------|
| 预设习惯 | 喝水(30min)、护眼(60min)、久坐(45min)、拉伸(90min) |
| 开关控制 | 每个习惯可独立开启/关闭 |
| 桌面通知 | 开启后到时间弹出浏览器桌面通知（电脑右下角） |
| 页面Toast | 手机端或通知被阻止时，页面内弹出提示 |
| 快速打卡 | 喝水/拉伸/护眼 一键+1 |
| 今日统计 | 显示当天各项打卡次数 |
| 自定义习惯 | 支持新增/编辑习惯（名称、图标、间隔、描述） |

**数据字段**: name, icon, intervalMinutes, enabled, description

### 3.5 每日计划
| 功能 | 描述 |
|------|------|
| 预设任务 | 7个固定任务，按时间排列：早餐(7:30)、八段锦(8:00)、阅读(9:00)、备考(10:00)、练字(14:00)、运动(17:00)、护肤(21:00) |
| 勾选打卡 | 点击左侧圆圈切换完成/未完成 |
| 时间排序 | 列表始终按时间升序排列 |
| 编辑任务 | 弹窗可修改任务名称和时间，修改时间后自动重排 |
| 新增任务 | 自定义任务名+时间 |
| 删除任务 | 预设和自定义任务均可删除 |
| 运动方案 | 折叠面板：肩颈拉伸4步 + 增肌塑形5步 + 饮食建议 |
| 运动打卡 | 独立勾选框标记每日运动完成 |

**数据字段**: task, time(HH:mm), completed, date, isPreset

### 3.6 灵感存档
| 功能 | 描述 |
|------|------|
| 热门选题 | 内置10条短视频创作选题，可随机刷新 |
| 从选题创建 | 点击热门选题自动填入灵感表单 |
| 新增灵感 | 弹窗表单：标题、内容、标签（逗号分隔） |
| 编辑删除 | 点击卡片编辑，支持修改所有字段 |
| 卡片布局 | 2-3列响应式网格 |
| 标签显示 | 标签以蓝色小圆角标签展示 |

**数据字段**: title, content, tags[], date, source

### 3.7 每日总结（日记）
| 功能 | 描述 |
|------|------|
| 日期 | 自动填充今日日期，可手动修改 |
| 心情选择 | 5个Emoji：😊😌😐😢😡 |
| 文字输入 | 多行文本框，支持换行 |
| 插入图片 | FileReader → base64 存储，可多张 |
| 图片预览 | 点击图片放大查看 |
| 历史列表 | 按日期倒序展示所有总结 |

**数据字段**: date, mood, content, images[](base64)

### 3.8 赚钱记录（记账）
| 功能 | 描述 |
|------|------|
| 月度汇总 | 顶部大号数字显示本月总收入 |
| 表格视图 | 日期 / 项目 / 金额 / 备注 / 操作 |
| 新增记录 | 弹窗表单：日期、项目、金额、备注 |
| 编辑删除 | 每行可编辑/删除 |
| 自动计算 | 本月总收入自动汇总（computed） |
| 排序 | 按日期倒序 |

**数据字段**: date, project, amount, notes

### 3.9 学习备考
- 记录学习科目、时长（分钟）、日期、备注
- 列表展示 + 增删改

### 3.10 读书记录
- 记录书名、作者、阅读页数、日期、笔记
- 列表展示 + 增删改

### 3.11 运动记录
- 记录运动类型（肩颈拉伸/增肌塑形/其他）、时长、日期、内容
- 列表展示 + 增删改

## 4. 非功能需求

| 需求 | 描述 |
|------|------|
| 离线可用 | Service Worker 缓存全部静态资源，首次加载后可离线打开 |
| 本地存储 | 所有数据存 localStorage，不上传服务器 |
| 数据导出 | JSON 格式导出全部数据，可下载为文件 |
| 数据导入 | 从 JSON 文件恢复数据 |
| 数据清除 | 一键清除全部数据（有确认弹窗） |
| 响应式 | 手机 375px ~ 桌面 1920px 均良好显示 |
| PWA | 可添加到手机主屏幕，独立窗口运行 |
| 通知权限 | 首次使用时请求桌面通知权限 |

---

## 5. 数据安全

- 数据完全保存在用户设备浏览器中
- 清除浏览器缓存/数据会导致数据丢失
- 建议用户定期导出 JSON 备份
- 不支持云端同步（无需账号）
